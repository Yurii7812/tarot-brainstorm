# タロット・ブレインストーミング

普通のブレインストーミングができて、その道具として **デッキ（タロット・易・発想カード）** を引いて使えるデスクトップアプリ（Electron。ブラウザは使わない）。
YuriiNote に組み込めるように、盤面（ブレスト本体）とデッキを分けて作っている（組み込むかどうか・いつかは利用者が決める）。設計の理由は `docs/BRAINSTORM_RESEARCH.md`。

入れ方: `install/linux.sh` を一度実行 → メニューの「タロット・ブレインストーミング」か `tarot-brainstorm` で起動（最大化で開く）。

## 作る（新規・Ctrl+N。ひな形は作ったあと変えない）
- ブレスト: 中心テーマから / 自由 / SWOT / 2×2 / 良い点・悪い点
- タロット: ヘキサグラム・3枚・1枚 / 📷 写真から（並べたカードを撮った写真から読み込む）
- 易: 本卦と之卦（コインを6回投げる）
- 発想カード: テーマのまわりに3枚

見た目は YuriiNote に合わせた白い画面（色があるのはカードの絵だけ）。上のバーは 題・元に戻す・引く ▾・新規・一覧・書き出し だけ。

## 盤面の操作（YuriiNote のブレストボードと同じ）
- クリック＝文字（箱なし）／ドラッグ＝ペン
- カードや文字をクリック＝それとつながった入力欄が出る。書いている間: Enter＝次、Tab＝そこから広げる、Shift+Tab＝元へ、Esc＝終わる
- カードや文字から別のものへドラッグ＝つなぐ（線はどれも同じ細い線）。空きに離すと、つながった新しい文字
- Ctrl+ドラッグ＝動かす（空きなら画面を動かす）。右ドラッグでも画面を動かせる
- 右クリック＝メニュー（文字・ペンの線は消す）。線を右クリック＝ひとことを書く・消す
- ホイール＝拡大縮小。カードにマウスを乗せると、位置の意味とカードの意味

## 右の詳細
- カード: 大きな絵、正逆の説明、絵の中にあるもの（押すとそれを起点に書く）、そのカードの問い、つながり、この位置での読み、自分の解釈
- 何も選んでいないとき: 概要（カードの一覧とまとめ）

## 引く（Ctrl+D・▾ でデッキと引き方）
- 空いた枠を埋める。枠がなければ、選んだものにつないで1枚置く。カードは最初から表
- ▾ の中: デッキ（タロット・易・発想カード）、逆位置（出す／出やすさ）、使うカード、混ぜ方、乱数の元（OS乱数・言葉から・マウスでかき混ぜる・時刻）、発想カードの種類
- 写真から（新規の「写真から」か、画像を窓にドロップ）: 端末の中だけで照合（OpenCV.js の AKAZE 特徴量＋射影変換。照合は Web Worker）。見つからないカードは確認画面で足す

## キー（Ctrl だけ）
D 引く / O 保存した一覧 / N 新規 / S 書き出し（.md と .png を並べて保存）/ Z・Y 元に戻す・やり直す / 0 全体
Ctrl なし: Tab 広げる / Enter 次・書き直す / Delete 消す / 矢印 近くへ移る / Esc 選択を外す

2026-11-18 に操作を減らした（Shift の範囲選択・右長押しの移動・6種類の色分け・線の種類・枠で囲む・一覧表示タブ・ペンの色・山札の絵を外した）。前に作った盤面の色分けや線の種類のデータは残っていて、表示は普通の文字・線になる。

## ファイル
`core.js` 状態・保存・ひな形・線の経路 / `board.js` 盤面 / `panels.js` 詳細・メニュー・一覧表示 / `draw.js` 引く / `dialogs.js` 新規・一覧・写真 / `export.js` 書き出し / `photo.js`・`photo-worker.js` 写真認識 / `decks/` デッキ
カードの説明・易の説明・発想カードの文面は、このアプリ用に書いたもの（小冊子・解説書・古典の訳文は使っていない）。

## 試験
`TAROT_TEST=1` で起動すると窓を出さずに描く（`--remote-debugging-port` と組み合わせて CDP で操作する）。`--user-data-dir` を別にして、本物の保存データを汚さないこと。
