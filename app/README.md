# タロット・ブレインストーミング

Electron のデスクトップアプリ（ブラウザは使わない）。画面は `app/`、外枠は `main.js`・`preload.js`。
入れ方: `install/linux.sh` を一度実行 → メニューの「タロット・ブレインストーミング」か `tarot-brainstorm` で起動（最大化で開く）。

## 画面（1画面・スクロールなし）
- 左: テーブル（盤面）。右: 選んだカードの詳細（正逆のキーワード・位置の意味・①標準の意味 ②この位置での読み ③自分の解釈・絵を読む問い）。何も選ばなければ、位置の一覧・まとめ・引いた記録。
- カードにマウスを乗せると、位置の意味とカードの正逆キーワードが出る。

## 盤面の操作（YuriiNote のブレストボードと同じ考え方）
- クリック＝文字（箱なし）／ドラッグ＝ペン／右クリック＝消す（カードはメニュー）
- カードから別のカードへドラッグ＝つなぐ（→流れ／↔ぶつかり、ひとこと）
- Ctrl+ドラッグ＝カード・文字を動かす（空きなら画面を動かす）／ホイール＝拡大縮小

## 引く
- 🂠 引く（Ctrl+D）か左下の山札: 空いた位置に伏せて配る → クリックかめくる（Ctrl+R）で表に。
- ⚙ 引き方: 逆位置なし／あり（確率）、使うカード（78枚・大・小）、乱数の元（OS乱数・言葉から＝再現できる・マウスでかき混ぜる・時刻）、混ぜ方（一度で完全に・リフルN回＋カット）、引き直しの間隔（分）。種は記録して .md に残す。
- カード名で置く: 位置を選んで名前・略号を打ち Enter（数字0〜21、w/c/s/p＋a,2〜10,pg,kn,q,k、末尾 r で逆位置）。

## キー（Ctrl だけ）
D 引く / R 全部めくる / B カードを足す / N 新しい読み / S 書き出し（.md と .png を並べて保存）/ Z・Y 元に戻す・やり直す / 0 全体を表示 / Esc 選択を外す

## 未対応
ホースシュー・二者択一・ケルト十字、写真からの認識（`recognition/`）、コートカード順の切替。
キーワードはこのアプリ用に書いた短い日本語（小冊子・解説書の文章は使っていない）。
