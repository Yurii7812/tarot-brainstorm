# タロット・ブレインストーミング

普通のブレインストーミングができて、その道具として **デッキ（タロット・易・発想カード）** を引いて使えるデスクトップアプリ（Electron。ブラウザは使わない）。
あとで YuriiNote に組み込む前提で、盤面（ブレスト本体）とデッキを分けて作っている。設計の理由は `docs/BRAINSTORM_RESEARCH.md`。

入れ方: `install/linux.sh` を一度実行 → メニューの「タロット・ブレインストーミング」か `tarot-brainstorm` で起動（最大化で開く）。

## 作る（新規・Ctrl+N。ひな形は作ったあと変えない）
- ブレスト: 中心テーマから / 自由 / SWOT / 2×2 / 良い点・悪い点
- タロット: ヘキサグラム・3枚・1枚 / 📷 写真から（並べたカードを撮った写真から読み込む）
- 易: 本卦と之卦（コインを6回投げる）
- 発想カード: テーマのまわりに3枚

## 盤面の操作
- クリック＝文字（箱なし）／ドラッグ＝ペン／Shift+ドラッグ＝範囲選択
- カードやアイデアをクリック＝それとつながった入力欄が出る。書いている間: Enter＝次、Tab＝そこから広げる、Shift+Tab＝元へ、Ctrl+1〜6＝種類（気づき・気持ち・心配・よい面・行動・問い）、Esc＝終わる
- ノードから別のノードへドラッグ＝つなぐ（カードどうしは「流れ」、ひとことを書ける）。空きに離すと、つながった新しいアイデア
- 右ボタン長押し・右ドラッグ＝動かす（選んだものはまとめて）。空きを右ドラッグ＝画面を動かす。短い右クリック＝メニュー（文字・ペンの線は消す）
- 線を右クリック＝種類（線・流れ・ぶつかり）・向き・消す。枠の見出しをドラッグ＝中身ごと動かす、右下の角＝大きさ
- ホイール＝拡大縮小。カードにマウスを乗せると、位置の意味とカードの意味

## 右の詳細
- カード: 大きな絵、正逆の説明、絵の中にあるもの（押すとそれを起点に書く）、そのカードの問い、つながり（他のカード・広げたアイデア）、この位置での読み、自分の解釈
- 何も選んでいないとき: 概要（まとめ）と一覧表示（箇条書きの木。ここで書くと盤面にも出る）

## 引く（Ctrl+D・▾ でデッキと設定）
- 空いた枠を埋める。枠がなければ、選んだものにつないで1枚置く。カードは最初から表
- タロット: 逆位置なし/あり（出やすさ）、78枚・大・小、混ぜ方（完全に・リフルN回＋カット）
- 乱数の元（共通）: OS乱数・言葉から（同じ言葉なら同じ結果）・マウスでかき混ぜる・時刻
- 写真から: 端末の中だけで照合（OpenCV.js の AKAZE 特徴量＋射影変換。照合は Web Worker）。見つからないカードは確認画面で足す

## キー（Ctrl だけ）
D 引く / G 枠で囲む / E 一覧表示 / O 保存した一覧 / N 新規 / S 書き出し（.md と .png を並べて保存）/ Z・Y 元に戻す・やり直す / 0 全体
Ctrl なし: Tab 広げる / Enter 次・書き直す / Delete 消す / 矢印 近くへ移る / Esc 選択を外す

## ファイル
`core.js` 状態・保存・ひな形・線の経路 / `board.js` 盤面 / `panels.js` 詳細・メニュー・一覧表示 / `draw.js` 引く / `dialogs.js` 新規・一覧・写真 / `export.js` 書き出し / `photo.js`・`photo-worker.js` 写真認識 / `decks/` デッキ
カードの説明・易の説明・発想カードの文面は、このアプリ用に書いたもの（小冊子・解説書・古典の訳文は使っていない）。

## 試験
`TAROT_TEST=1` で起動すると窓を出さずに描く（`--remote-debugging-port` と組み合わせて CDP で操作する）。`--user-data-dir` を別にして、本物の保存データを汚さないこと。
