# タロット・ブレインストーミング（最小版）

Electron のデスクトップアプリ（ブラウザは使わない）。画面部分は `app/`、外枠は `main.js`。
起動: リポジトリ直下で `./tarot.sh`（初回だけ `npm install` と Electron 本体の取得が走る）。

## 使い方
- スプレッドを選ぶ（ヘキサグラム7枚 / 3枚 / 1枚）。位置が自動で配置される。
- 位置をクリック → カード名・略号を打って Enter → 次の空き位置へ自動で移る。
  - 略号: 大アルカナは数字 `0`〜`21`、小アルカナは `w/c/s/p` ＋ `a`,`2`〜`10`,`pg`,`kn`,`q`,`k`（例 `w10`, `ckn`）。末尾 `r` で逆位置（`14r`）。日本語・英語名の一部でも検索可。
- 各位置に3つの欄: ① 標準の意味 ② この位置での読み ③ 自分の解釈。
- つながり: 流れ（灰色の実線）/ ぶつかり（赤の点線）。位置を選んで別の位置を Ctrl+クリックでも追加。
- 「.md を出力」「画像を出力」で書き出し（画像は PNG、.md から参照）。
- 入力は自動でブラウザ（localStorage）に保存。上部の一覧から過去の読みを開ける。
